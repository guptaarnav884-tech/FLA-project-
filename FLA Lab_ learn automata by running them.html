Finite automata: DFA and NFA

A finite automaton reads a string one symbol at a time and decides yes or no using only its current state. A DFA has exactly one move for every symbol. An NFA may have several moves, or none, and accepts if any path works.

Regular expressions

A regular expression describes a language with | (or), * (repeat), ? (optional) and brackets. Every regex has an equivalent NFA, and every NFA has an equivalent DFA.

The Chomsky hierarchy

Each ring can do everything inside it, plus more.

Type 0: Turing machine, any computable language, such as the halting problem’s yes-instances
Type 1: linear bounded automaton, such as aⁿbⁿcⁿ
Type 2: PDA and context-free grammar, such as aⁿbⁿ and w c wᴿ
Type 3: DFA, NFA and regular expression, such as a*b* and strings that end in 01

Glossary

Alphabet, string, language

An alphabet is a finite set of symbols. A string is symbols in a row. A language is a set of strings.

DFA

Deterministic finite automaton: exactly one move for every state and symbol.

NFA and ε-moves

Nondeterministic finite automaton: several or no moves per symbol. An ε-move changes state without reading input. Accepts if any path accepts.

Subset construction

Turns any NFA into a DFA whose states are sets of NFA states. The DFA can be exponentially larger.

Regular expression and Kleene’s theorem

Regexes, DFAs and NFAs all describe exactly the regular languages.

Context-free grammar

Rewrite rules like S → aSb | ε. A derivation applies rules from S until only terminals remain. A grammar is ambiguous if one string has two parse trees.

PDA

A finite automaton plus a stack. It recognises exactly the context-free languages.

Turing machine

A finite control with an endless tape. It models everything a computer can compute.

Pumping lemma

Every long enough string in a regular language has a part that can be repeated and stay in the language. Used to prove a language such as aⁿbⁿ is not regular.

Closure properties

Regular languages are closed under union, concatenation, star, complement and intersection. Context-free languages are not closed under intersection or complement.

Decidable and undecidable

A problem is decidable if some Turing machine always halts with the right answer. The halting problem is undecidable.

Minimization

Every regular language has a unique smallest DFA, found by merging states that behave the same.

New to FLA? Start here

  1. Alphabet and strings. An alphabet is a set of symbols, like {0, 1}. A string is symbols in a row, like 0110.
  2. Language. A language is a set of strings that follow a rule, like “a’s then the same number of b’s”.
  3. Automata. Machines that decide whether a string is in a language. A finite automaton has no memory, a pushdown automaton (PDA) adds a stack, and a Turing machine can compute anything computable.
  4. Why it matters. Compilers, search, form checks and protocol checkers all rely on these ideas.
